Epoch 1: input noise / output

Epoch 5: input noise / output

Mean of all training digits

Every output is the same blurry blob, which looks like all the digits 0 to 9 stacked on top of each other and closely matches the mean training digit. The noise input carries no information about which digit is the target, so the best prediction under MSE is the same output every time, which is the average of all the digits.
